## Moderation

{/* source: packages/sushii-worker/src/features/moderation/audit-logs/domain/entities/AuditLogEvent.ts#AuditLogEvent.fromDiscordEntry @97eaa488 */}

sushii gives every ban, kick, timeout, and warn a case number, whether it came
from sushii's commands or Discord's own tools.

See the [Moderation Guide](/docs/guides/moderation_guide) for the full
workflow.

## XP & Leveling

Members earn XP by chatting, with automatic role rewards at configurable level
milestones. See who's most active with the leaderboard.

See the [XP & Levels Guide](/docs/guides/xp-levels) for setup.

{/* source: packages/sushii-worker/src/features/leveling/presentation/commands/RankCommand.ts#RankCommand @ffa4ebdc, packages/sushii-worker/src/features/leveling/presentation/commands/LeaderboardCommand.ts#LeaderboardCommand.command @2a28a932, packages/sushii-worker/src/features/leveling/presentation/commands/LevelRoleCommand.ts#CommandName @8f68a1cc, packages/sushii-worker/src/features/leveling/presentation/commands/XpCommands.ts#XpGroupName @9b7f8b43 */}

| Command | What it does |
|---|---|
| `/rank` | View your rank and XP (or another member's) |
| `/leaderboard` | Server XP leaderboard, filterable by day / week / month / all time |
| `/levelrole new` | Award a role automatically when a member reaches a level |
| `/levelrole delete` | Remove a level role reward |
| `/levelrole list` | List all configured level roles |
| `/xp block` | Exclude a channel or role from earning XP |
| `/xp unblock` | Re-enable XP earning for a channel or role |

## Social

{/* source: packages/sushii-worker/src/features/social/domain/constants/SocialConstants.ts#SOCIAL_COOLDOWN_HOURS @90a38ea2, packages/sushii-worker/src/features/social/presentation/commands/RepCommand.ts#RepCommand @eafcc8fe, packages/sushii-worker/src/features/social/presentation/commands/FishyCommand.ts#FishyCommand @5b4b85ff, packages/sushii-worker/src/features/social/presentation/commands/RepLeaderboardCommand.ts#RepLeaderboardCommand @1e5b9c2a, packages/sushii-worker/src/features/social/presentation/commands/FishyLeaderboardCommand.ts#FishyLeaderboardCommand.command @2172dcc3 */}

Reputation lets members vouch for each other. Fishies is a fishing minigame you can play every 12 hours.
Both have server leaderboards.

| Command | What it does |
|---|---|
| `/rep` | Give reputation to another member |
| `/rep-leaderboard` | Server reputation leaderboard |
| `/fishy` | Catch fish (every 12 hours) |
| `/fishy-leaderboard` | Server fishy leaderboard |

{/* source: packages/sushii-worker/src/features/social/domain/entities/Streak.ts#calculateStreak @c7a1c763, packages/sushii-worker/src/features/social/domain/entities/Streak.ts#getStreakMultiplier @1836d66b, packages/sushii-worker/src/features/social/domain/constants/StreakConstants.ts#STREAK_MULTIPLIER_CAP @eabc0a19, packages/sushii-worker/src/features/social/domain/entities/Streak.ts#rollRepAmount @09b9e933 */}

Using `/fishy` or `/rep` at least once each UTC day builds a separate daily streak for each.
Skipping a full UTC day resets that streak. From a 7 day streak, the fishies you catch are
multiplied by 1.1x, gaining another +10% each time the streak doubles (14 days 1.2x, 28 days 1.3x),
up to 1.5x from 112 days. For rep, the bonus is a chance to give 2 rep instead of 1 (10% at a 1.1x
streak).
