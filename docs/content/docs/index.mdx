<Steps>

<Step>

### Invite sushii

[Add sushii to your server](https://discord.com/oauth2/authorize?client_id=193163942502072320&permissions=1615243635910&scope=applications.commands+bot)
and keep every permission it asks for. sushii needs **View Audit Log** to record
bans, kicks, and timeouts done through Discord, and its role has to sit above
any role it assigns or acts on.

</Step>

<Step>

### Open the settings panel

{/* source: packages/sushii-worker/src/features/guild-settings/presentation/commands/SettingsCommand.ts#SettingsCommand.command @2efb7eae, packages/sushii-worker/src/features/guild-settings/presentation/views/panel/SettingsPanel.ts#TAB_LABELS @6e5db27b, packages/sushii-worker/src/features/guild-settings/presentation/views/panel/panelParts.ts#editButton @50070615, packages/sushii-worker/src/features/guild-settings/presentation/views/panel/panelParts.ts#toggleButton @ccc0b67d, packages/sushii-worker/src/features/guild-settings/presentation/views/panel/SettingsPanel.ts#FOOTER_TEXT @f0800697 */}

Run `/settings` in any channel. This opens a panel with five tabs: **Overview**,
**Logging**, **Moderation**, **Automod**, and **Welcome**.

Each row shows its current state and flags anything that needs attention.
Click **Edit** to change a setting, or **Turn on** / **Turn off** for simple switches.
Changes save as soon as you make them.

{/* source: packages/sushii-worker/src/features/guild-settings/presentation/views/panel/OverviewPanel.ts#attentionLine @06284cbd, packages/sushii-worker/src/features/guild-settings/presentation/views/panel/panelParts.ts#attentionDetail @b7653117, packages/sushii-worker/src/features/guild-settings/application/SettingsStatus.ts#AttentionProblem @11e44f4d, packages/sushii-worker/src/features/guild-settings/application/SettingsStatus.ts#computeSettingsStatus @4a0f6c8a */}

The **Overview** tab sums up each tab and lists anything that **needs
attention**, such as a log channel that was deleted, a channel sushii is
missing permissions in, or a join message that's on with no channel picked.

</Step>

<Step>

### Set up a mod log channel

If you plan to use sushii for moderation, the most important first step is
pointing it to a private moderation log channel:

{/* source: packages/sushii-worker/src/features/guild-settings/presentation/views/panel/SettingsPanel.ts#TAB_LABELS @6e5db27b, packages/sushii-worker/src/features/guild-settings/presentation/views/panel/LoggingPanel.ts#LOG_ROWS @b9ef4da2, packages/sushii-worker/src/features/guild-settings/application/GuildSettingsService.ts#applyPatch @8f995578 */}

```
/settings → Logging → Mod log → Edit
```

Picking a channel turns the log on. Clearing the channel turns it off.

{/* source: packages/sushii-worker/src/features/moderation/audit-logs/domain/entities/AuditLogEvent.ts#AuditLogEvent.fromDiscordEntry @97eaa488 */}

sushii posts every moderation case there, including bans, kicks, and timeouts
done through Discord itself.

</Step>

<Step>

### Turn on the features you want

From `/settings` you can also set up:

{/* source: packages/sushii-worker/src/features/guild-settings/presentation/modals/dmModals.ts#buildTimeoutModal @f686289e, packages/sushii-worker/src/features/guild-settings/presentation/modals/logModals.ts#LOGS @af5b9db3, packages/sushii-worker/src/features/guild-settings/presentation/modals/dmModals.ts#buildWarnModal @5ed3183c, packages/sushii-worker/src/features/guild-settings/presentation/views/panel/WelcomePanel.ts#addWelcomePanel @416fc764, packages/sushii-worker/src/features/guild-settings/presentation/modals/dmModals.ts#buildBanModal @c5e5f8b1, packages/sushii-worker/src/features/guild-settings/presentation/modals/dmModals.ts#buildKickModal @22343e37, packages/sushii-worker/src/features/guild-settings/presentation/modals/dmModals.ts#EXTRA_TEXT_DESCRIPTION @53ee7147, packages/sushii-worker/src/features/guild-settings/presentation/views/panel/ModerationPanel.ts#"Lookup sharing" @25dae587, packages/sushii-worker/src/features/guild-settings/presentation/views/panel/AutomodPanel.ts#"Scam images" @f9369c06, packages/sushii-worker/src/features/guild-settings/presentation/views/panel/AutomodPanel.ts#"Times out cross-channel spam" @a1ed370b, packages/sushii-worker/src/features/guild-settings/presentation/views/panel/AutomodPanel.ts#"Actions are always logged in " @a8005e17 */}

- **Logging** — message edits and deletes, member joins and leaves, and removed reactions, each in its own channel
- **Moderation** — whether sushii DMs members when they're timed out, kicked, or banned, extra text for those DMs and for warnings, and whether other servers can see your server name and ban reasons in `/lookup`
- **Automod** — scam image detection, spam detection, and an alerts channel for automod actions
- **Welcome** — custom join and leave messages sent to a channel

{/* source: packages/sushii-worker/src/features/guild-settings/presentation/views/panel/OverviewPanel.ts#"More setup:" @310d3bcd */}

Level roles, role menus, schedule channels, and tags have their own commands,
listed at the bottom of the Overview tab.

You don't have to set everything up at once. Come back to `/settings` whenever
you're ready to add more.

</Step>

## Setting up XP & Leveling

{/* source: packages/sushii-worker/src/features/leveling/application/UpdateUserXpService.ts#UpdateUserXpService.execute @6492f1d2, packages/sushii-worker/src/features/leveling/presentation/commands/LevelRoleCommand.ts#LevelRoleOption @1d5f4f60 */}

XP earning is on by default once members start chatting. To reward members for
reaching certain levels, use `/levelrole`:

```
/levelrole new role:<role> add_level:<level>
```

Optionally set `remove_level` if you want the role removed when the member
reaches a higher tier (role progression).

{/* source: packages/sushii-worker/src/features/leveling/presentation/commands/XpCommands.ts#XpGroupName @9b7f8b43, packages/sushii-worker/src/features/leveling/presentation/commands/XpCommands.ts#XpCommandName @03805b75 */}

To stop XP from being earned in specific channels or by specific roles:

```
/xp block channel <channel>
/xp block role <role>
/xp block list
```

See the [XP & Levels guide](/docs/guides/xp-levels) for more detail.

## Setting up role menus

Role menus let members self-assign roles from an interactive message. They are
configured with `/rolemenu`, not `/settings`.

{/* source: packages/sushii-worker/src/features/role-menu/presentation/commands/RoleMenuCommand.ts#RoleMenuOption @14bb7fa7 */}

```
/rolemenu create menu_name:<name>
```

This opens an interactive builder where you can add roles, set descriptions and
emoji, and cap how many roles a member can pick at once. When you're done, use
`/rolemenu send` to post it to a channel.

The `/settings` and `/permission-audit` panels have a **Feedback** button at
the bottom, and unexpected errors titled **Something went wrong** have a **Send
feedback** button. Either one opens a short form that goes straight to the sushii team. You can
send up to 3 per hour.
